# Changelog / История изменений

## 0.3.0 — 2026-10-28

### English

- GitLab Deck becomes **Forge Deck**, a terminal workspace for GitHub and GitLab.
- GitHub repositories, organizations, involved PRs, code, branches, diffs, general PR comments, Actions runs, jobs, and logs.
- Confirmed GitHub CI rerun/cancel actions and eight administrator-only repository settings.
- Existing GitLab project, group, MR, pipeline, job, log, and project-settings workflows.
- Platform switching, server-scoped favorites, GitHub Enterprise and self-managed GitLab support.
- English and Russian UI, language switching, and migration from GitLab Deck preferences; the `gitlab-deck` command remains compatible.
- MIT license and first official binary release, with native Linux x86_64/ARM64 CI, archive smoke checks, build information, and SHA256 checksums.

### Русский

- GitLab Deck переименован в **Forge Deck** — терминальное пространство для GitHub и GitLab.
- Репозитории и организации GitHub, PR с вашим участием, код, ветки, диффы, общие комментарии PR, Actions, джобы и логи.
- Повтор и отмена CI GitHub с подтверждением, восемь настроек репозитория для администратора.
- Сохранены сценарии GitLab: проекты, группы, MR, пайплайны, джобы, логи и настройки проекта.
- Переключение платформ, избранное с привязкой к серверу, поддержка GitHub Enterprise и собственных серверов GitLab.
- Интерфейс EN/RU, переключение языка и перенос настроек GitLab Deck; команда `gitlab-deck` продолжает работать.
- MIT и первый официальный бинарный релиз: нативный CI Linux x86_64/ARM64, проверки архивов, сведения о сборке и SHA256.
