# ADR-0001 · Терминал и авторизация

Статус: принято.

Самостоятельный Rust-клиент с навигацией по проектам, репозиторию, MR и CI.

Интерфейс строится на Ratatui и Crossterm. Приложение самостоятельно управляет состоянием экранов, навигацией, поиском и оформлением.

Доступ к GitLab REST API v4 выполняется через установленный `glab api`. Это позволяет использовать штатный вход и существующие локальные доступы без второго хранилища токенов. HTTP-контракты остаются контрактами GitLab, а не форматом экранного вывода CLI.

Вызовы выполняются вне потока интерфейса. Каждому запросу назначаются отмена и тайм-аут; устаревший ответ не заменяет данные нового экрана. Число одновременно работающих сетевых дочерних процессов ограничено одним.

Изменения настроек, повтор, запуск и отмена CI требуют явного подтверждения в приложении. Проверки разработки используют деморежим и подставной CLI; реальные мутации не запускаются.

Токены не читаются приложением из файлов, не записываются на диск и не попадают в аргументы. Настройки приложения содержат только адрес сервера и избранные проекты. Тела изменяющих запросов передаются через stdin.

Цена решения: для живого подключения необходим установленный и авторизованный `glab`. Прямой HTTP-клиент понадобится только при доказанном ограничении этого способа.
