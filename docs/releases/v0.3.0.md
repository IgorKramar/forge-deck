## English

**Forge Deck 0.3.0** brings GitHub and GitLab into one terminal workspace, with a Tokyo Night theme, rounded panels, keyboard navigation, and English/Russian UI.

- Browse repositories/projects, organizations/groups, files, branches, and PRs/MRs.
- Read descriptions, diffs, general comments, CI runs, jobs, and logs.
- Rerun or cancel supported CI actions; start manual GitLab jobs.
- Edit supported repository/project settings with an explicit confirmation.
- Switch platforms with `G`, change servers with `H`, switch EN/RU with `L`.
- Keep authentication in `gh` and `glab`; try either platform offline with `--demo`.

This is the first official binary release under the MIT license. The `gitlab-deck` compatibility command is included. Existing GitLab Deck settings are migrated when the new file is absent; the old file remains unchanged.

### Downloads

Choose `x86_64-unknown-linux-gnu` for Intel/AMD 64-bit Linux or `aarch64-unknown-linux-gnu` for ARM64 Linux. Both builds use glibc on Ubuntu 22.04; musl/Alpine binaries are not provided. Verify the selected archive against `SHA256SUMS` before extracting. Both commands, documentation, and `BUILDINFO.json` with the source commit and target are included.

No Rust toolchain is required for these binaries. Install `gh` and/or `glab` for real connections. CI tests use offline demo data and a fake CLI; they do not modify real repositories. The application does not post comments, merge PRs/MRs, or administer instances; see the README for API and platform limits.

## Русский

**Forge Deck 0.3.0** объединяет GitHub и GitLab в одном терминале: тема Tokyo Night, скруглённые панели, управление клавиатурой и интерфейс EN/RU.

- Репозитории и проекты, организации и группы, файлы, ветки, PR и MR.
- Описания, диффы, общие комментарии, запуски CI, джобы и логи.
- Повтор и отмена поддерживаемых действий CI, запуск ручных джоб GitLab.
- Изменение доступных настроек репозитория или проекта с явным подтверждением.
- `G` переключает платформы, `H` — сервер, `L` — язык EN/RU.
- Авторизацией управляют `gh` и `glab`; обе платформы можно попробовать без сети через `--demo`.

Это первый официальный бинарный релиз под MIT. Совместимая команда `gitlab-deck` входит в архив. Если нового файла настроек нет, читаются настройки GitLab Deck; старый файл остаётся неизменным.

### Загрузка

Для Intel/AMD 64-bit Linux выберите `x86_64-unknown-linux-gnu`, для ARM64 Linux — `aarch64-unknown-linux-gnu`. Обе сборки используют glibc и Ubuntu 22.04; бинарников musl/Alpine нет. Перед распаковкой сверьте выбранный архив с `SHA256SUMS`. В архив входят обе команды, документация и `BUILDINFO.json` с коммитом исходников и платформой.

Rust для готовых бинарников не нужен. Для настоящих подключений установите `gh` и/или `glab`. CI работает с демоданными и подставным CLI, не изменяя реальные репозитории. Приложение не отправляет комментарии, не сливает PR/MR и не администрирует инстансы; ограничения API и платформ описаны в README.
